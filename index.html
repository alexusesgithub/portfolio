Ansible Failure Whisperer

LLM diagnostics for automation failures

Built an LLM diagnostics tool that turns failed Ansible/AWX runs into plain-English root causes. It runs entirely on local inference, so no log data ever leaves the environment.

At a glance

Role
Builder
Stack
Python, Qwen 3.5B (local inference), Ansible, AWX
  • Local LLM inference: no external API calls and no data leaving the environment
  • Built for enterprise and security-sensitive infrastructure where cloud LLMs are off the table
  • Pulls the failed task and its log context out of noisy AWX output before prompting
  • Prompts keep explanations grounded in what the logs actually show
